# Public CAR input data

This directory contains the 18 municipal CSV extracts used by the paper. The files were downloaded from the official Consulta Pública do Cadastro Ambiental Rural geoservices portal on 21 September 2026. Their names identify the state, municipality, and thematic layer.

The corresponding SHA-256 checksums, row counts, and distinct property identifiers are recorded in `../../manifesto_fontes_publicas.csv`.
